# 🎮 Video Game Sales Analysis

This project analyzes a video game sales dataset using **Python** to identify sales patterns, regional performance, popular genres, platforms, publishers, and user engagement.

##  What I Worked On

- Data exploration and understanding
- Data cleaning and handling missing values
- Data type conversion
- Feature engineering
- Sales categorization
- Year categorization
- Regional sales analysis
- Platform-wise global sales analysis
- Genre-wise game analysis
- User review analysis
- Data visualization using **Matplotlib** and **Seaborn**
- Exploratory Data Analysis (EDA)

##  Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

##  Key Analysis

The project explores:

- Which platforms generate the highest global sales
- Which genres have the most games
- Sales distribution across North America, Europe, Japan and other regions
- User reviews across different genres
- Global sales distribution
- Publisher performance
- Sales trends based on release year

##  Objective

The main objective of this project is to practice **real-world data cleaning, feature engineering, exploratory data analysis and visualization** using Python and extract meaningful insights from video game sales data.
